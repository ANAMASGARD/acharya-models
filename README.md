Public, versioned model artifacts used by the Acharya Android app. No application source, classroom content, account information, or credentials are stored here.

## Gemma 3 270M IT Q8

The `gemma3-270m-it-q8-v1` release contains the unchanged `gemma3-270m-it-q8.litertlm` artifact (304,005,120 bytes). This is a text-generation model for LiteRT-LM, distinct from EmbeddingGemma and Whisper.

Source distributor: [Moon Launcher models](https://huggingface.co/moonlauncher/moon-models/tree/bbf238fa1804f295ea05df88502ac97a4732db30), revision `bbf238fa1804f295ea05df88502ac97a4732db30`. The distributor identifies it as an unchanged copy from [LiteRT Community](https://huggingface.co/litert-community/gemma-3-270m-it). Acharya independently downloaded the full file and verified exact size and SHA-256 against the distributor's published LFS metadata. Its LFS pointer object ID matches the public official listing; direct authenticated comparison with the gated official full-file hash was not performed.

SHA-256: `757e9119fa5bd667a2774fb470ac4afcd3190a21c677f8e69a5d6bc908abdd63`.
